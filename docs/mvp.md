# MVP

Сделано:

- вход по email/паролю, JWT access + refresh
- пользователи (создание и блокировка админом)
- проекты, статусы, участники
- задачи, фильтры, канбан и список
- workflow и история статусов
- комментарии
- внутрисистемные уведомления
- аналитика проекта и загрузка
- dashboard
- Swagger `/docs`

Отложено:

- ML-прогнозы и версии моделей
- вложения
- зависимости задач
- email/push
- настраиваемые workflow
- Gantt

Демо-пользователи: см. корневой README.
