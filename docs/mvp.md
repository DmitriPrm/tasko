# MVP

Сделано:

- вход по email/паролю, JWT access + refresh, регистрация с подтверждением почты
- пользователи (создание и блокировка админом), профиль, настраиваемые права ролей
- проекты, статусы, участники, приглашения по email, избранное
- задачи, фильтры, канбан с настраиваемыми колонками и список с сортировкой
- workflow и история статусов и изменений полей (срок, приоритет, исполнитель…)
- подзадачи и зависимости задач (блокирует / зависит от / связана), без циклов
- вложения к задачам (до 10 МБ, локальное хранилище `backend/storage/attachments`)
- начатую задачу нельзя удалить: она отменяется, история сохраняется
- комментарии
- внутрисистемные уведомления, в том числе ежечасные напоминания о приближении срока
- аналитика проекта и загрузка
- dashboard
- Swagger `/docs`

Отложено:

- ML-прогнозы и версии моделей (отдельный модуль `ml/`)
- email/push-уведомления о задачах
- настраиваемые workflow
- Gantt

Демо-пользователи: см. корневой README.
